작성 2026-11-26 · 2026년 11월 세법 기준

2026년 5월 10일부터 조정대상지역 집을 파는 다주택자에게 중과세율이 다시 붙어요. 이때는 장기보유특별공제도 사라져서, 같은 집들을 가지고 있어도 어떤 집을 먼저 파느냐에 따라 세금이 크게 달라져요.

순서를 정하는 세 가지 원칙

  1. 중과가 없는 집부터: 조정대상지역이 아닌 곳의 집은 다주택이어도 기본세율에 장기보유특별공제까지 받아요. 먼저 팔아 주택 수를 줄이면 다음 집의 중과 단계가 내려가요(3주택 30%p → 2주택 20%p).
  2. 차익이 작은 집부터: 중과는 차익이 클수록 무거워져요. 차익이 큰 집은 뒤로 미루는 게 보통 유리해요.
  3. 마지막 한 채는 비과세 요건을 채운 집으로: 마지막에 남는 1주택은 12억원까지 비과세이고, 넘어도 최대 80% 공제를 받아요. 오래 살았고 차익이 큰 집을 남기는 게 유리해요.

예시: 세 채를 가진 경우

아파트위치산 날짜 / 가격팔 가격거주
A서울 강남권2015년 3월 / 6억원14억원10년
B서울2020년 6월 / 5억원9억원없음
C비규제 지역2021년 9월 / 3억원4억원없음

2026년 12월에 두 채를 팔고 한 채를 남긴다고 하면, 순서에 따라 양도세(지방소득세 포함)가 이렇게 달라져요.

파는 순서남기는 집양도세 합계
C 아파트 → B 아파트A 아파트250,580,000원
B 아파트 → C 아파트A 아파트294,305,000원
C 아파트 → A 아파트B 아파트521,125,000원
A 아파트 → C 아파트B 아파트608,850,000원
B 아파트 → A 아파트C 아파트781,902,000원
A 아파트 → B 아파트C 아파트825,902,000원

가장 유리한 순서(C → B, A 보유)와 가장 불리한 순서의 차이가 575,322,000원예요. C는 비규제 지역이라 3주택이어도 중과가 없어서 먼저 팔고, 그다음 B를 2주택 중과로 판 뒤, 차익이 가장 큰 A를 1주택으로 남기는 구조예요.
